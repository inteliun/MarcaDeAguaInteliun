# Marca de Agua Inteliun

Aplicación de escritorio para añadir marcas de agua a uno o varios PDF.

## Uso

1. Descarga el archivo ZIP de la versión.
2. Descomprímelo.
3. Ejecuta `MarcaDeAguaInteliun.exe`.
4. Añade tus PDFs y configura la marca de agua.

No necesitas instalar Python.

## Funciones

- Marca de agua de texto.
- Marca de agua con imagen.
- Texto + imagen.
- Tamaño, color y opacidad.
- Ángulo de rotación.
- Posición central o mosaico.
- Procesamiento de varios PDFs.
- Carpeta de salida configurable.

## Para desarrolladores

```text
pip install -r requirements.txt
python marca_de_agua_inteliun.py
```

El ejecutable se genera con PyInstaller.
